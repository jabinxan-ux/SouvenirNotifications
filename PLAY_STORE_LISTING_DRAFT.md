# Fiche Google Play — texte à copier

Ébauche pour la fiche principale française. Google limite le nom à 30 caractères, la description courte à 80 et la description complète à 4 000 caractères. Les textes ci-dessous respectent ces plafonds; ils restent à relire avec les visuels définitifs.

## Nom de l’application

**Souvenir notifications** — 22 caractères

## Description courte

**Archive localement les notifications que tu choisis.** — 52 caractères

## Description complète

Souvenir conserve sur ton téléphone une copie des notifications que tu choisis, pour que tu puisses les retrouver dans un historique organisé.

• Active l’archivage séparément pour chaque application compatible.  
• Parcours l’historique, les conversations et les médias disponibles.  
• Recherche un nom ou un message, puis filtre par application.  
• Déplace un élément dans la corbeille avant de le supprimer définitivement.  
• Exporte ou restaure une sauvegarde depuis un emplacement choisi.

Souvenir ne récupère pas les messages supprimés depuis les applications. Elle conserve les informations qu’Android transmet dans les notifications. Le nom, la photo de profil et les aperçus dépendent de ce que l’application source et Android fournissent. Un aperçu ou une pièce jointe n’est archivé que si Android le transmet et le rend accessible; certaines notifications vidéo peuvent ne fournir que du texte.

En option, tu peux autoriser le dossier WhatsApp/Media. Souvenir y recherche les photos, vidéos et fichiers audio déjà téléchargés, puis copie les fichiers compatibles dans son espace privé. Le dossier est analysé à l’ouverture de l’application, après certaines notifications WhatsApp et périodiquement en arrière-plan tant que l’autorisation reste active. Tu peux retirer cet accès depuis Stockage et sauvegardes.

L’accès aux notifications est facultatif et contrôlé dans les réglages Android. Tu choisis les applications à archiver et tu confirmes leur activation dans Souvenir. Les notifications archivées restent dans l’espace privé de l’application sur ton téléphone. Souvenir n’a pas de compte utilisateur, de publicité intégrée ni de service en ligne pour envoyer ton archive.

Les sauvegardes ZIP ne sont pas chiffrées. Si tu choisis un emplacement cloud lors d’un export, ou une autre application pour partager un média, ce fournisseur reçoit le fichier ou le média sélectionné et applique ses propres règles.
